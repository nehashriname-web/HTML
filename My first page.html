HTML Formatting Tags

Tag Description
Paragraph A set of sentences that are put together to deal with a single subject.
Algorithm A step-by-step procedure used to solve a problem in detail.
Preformat A preformatted text for displaying text exactly as written using fixed width font.
Center Aligns the text or content to the center of the webpage.
Marquee Creates scrolling text or images on a webpage.
Ordered List & Unordered List
  1. Ordered List - Displays items in numbered format.
  • Unordered List - Displays items with bullet points.
Font Size This text is displayed using font size tag.
